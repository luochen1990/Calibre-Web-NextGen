### Fixed

- **With two or more Kobos and Share my place ticked, a Kobo that had read a book before now moves to the place you reached on another one.** A Kobo's book download doesn't say which Kobo is fetching it, so on an account with several Kobos CWNG could never confirm which copy of the book each one held. Without that, a Kobo was sent the new percentage but kept its own old page location, so the book opened where it was and no sync prompt appeared. Each Kobo's download link now names that Kobo. Books downloaded before this update are confirmed the next time the Kobo downloads them (remove the download on the Kobo and open it again from the library). Reported by @dwerkson (#2724).
